# ADR 0001: The LLM only detects; code locates and replaces

- Status: Accepted
- Date: 2026-10-06

## Context

The simplest approach would be to ask an LLM to return the document with identifying information replaced. LLMs asked to rewrite text tend to change wording, drop or add sentences, hallucinate and break formatting. They are also unreliable at returning exact character offsets.

## Decision

- The LLM returns a structured list of entity strings and types (and aliases), validated against a JSON schema.
- Code finds every occurrence of those strings in the original text and replaces them.
- The original document's text and formatting are never regenerated by a model.

## Consequences

- Output is deterministic given a set of entities, and the document is otherwise unchanged.
- Found entities can be shown to the user for review before applying.
- Matching needs care (normalisation, word boundaries, text split across DOCX runs).
- Entities the LLM paraphrases instead of quoting exactly may be missed; the rules and NER layers and the verification pass reduce this.
